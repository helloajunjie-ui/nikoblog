# nikoblog · 极简微博客

一个轻量、自托管的极简微博客系统。单二进制部署，前端与后端打包在一起，开箱即用。

> **作者**：niko　**Q群**：430291666

## ✨ 功能特性

- **博文发布**：支持 Markdown 语法，可插入图片，公开/仅自己两种可见性
- **标签系统**：在正文中输入 `#标签` 自动生成标签，点击标签即可筛选出所有包含该标签的博文
- **置顶功能**：管理员可将博文置顶（可设置截止时间，到期自动取消置顶），置顶博文始终排在列表最前
- **评论互动**：支持登录用户评论与游客（免注册）评论，评论可附图
- **用户中心**：头像上传、我回复过的主题（一键跳回原博文）、密保问答设置
- **账号安全**：注册即设置 3 个密保问答，忘记用户名/密码可通过密保找回
- **AI 润色**：后台配置 OpenAI 兼容 API 后，编辑器可一键调用 AI 润色博文
- **自动任务引擎**：定时抓取 RSS 数据源 → AI 洗稿 → 自动发布为公开博文，支持自定义洗稿指令
- **后台管理**：博客设置、用户管理、博文管理（含置顶）、标签管理、AI 与自动任务配置
- **深色模式**：跟随系统/手动切换
- **角色体系**：首个注册用户自动成为管理员（博主），可管理全站

## 🚀 快速开始

### 方式一：Docker（推荐）

```bash
# 构建并启动
docker compose up -d --build

# 访问
# http://localhost:8080
```

> 生产环境请务必设置 `NIKOBLOG_JWT_SECRET` 环境变量，例如：
> ```bash
> NIKOBLOG_JWT_SECRET=你的随机密钥 docker compose up -d --build
> ```

### 方式二：本地运行

需要 Go 1.26+ 与 Node.js 20+。

```bash
# 1. 构建前端
cd frontend
npm install
npm run build
cd ..

# 2. 编译后端（自动打包前端）
go build -o nikoblog ./cmd/server

# 3. 运行
./nikoblog
```

启动后访问 `http://localhost:8080`。

### 开发模式（热更新）

```bash
# 终端 1：后端
go run ./cmd/server

# 终端 2：前端（5173 端口，自动代理 API 到 8080）
cd frontend && npm install && npm run dev
```

## 📖 使用指南

### 注册与登录

- 打开首页，点击「立即登录」→「注册」。
- 注册需填写：用户名、密码、昵称、邮箱，以及 **3 个密保问答**（用于忘记账号时找回）。
- **第一个注册的用户自动成为管理员**，拥有后台管理权限。

### 发布博文

- 登录后，在首页顶部编辑器输入内容。
- 支持 Markdown 语法；工具栏提供加粗、斜体、标题、引用、列表、代码块、链接、**#标签** 等快捷按钮。
- 可上传图片（单张最大 5MB，支持 jpg/png/gif/webp）。
- 选择「公开」或「仅自己」后点击发布。
- 若后台已配置 AI 服务，编辑器提供「AI 润色」按钮，可一键优化排版与措辞。

### 使用标签

- 在博文正文中输入 `#标签名`（如 `#生活`、`#技术`），发布后自动生成标签。
- 首页左侧「热门标签」展示所有标签及其博文数量，点击即可筛选出包含该标签的所有博文，再次点击取消筛选。

### 评论

- 打开任意博文详情，在底部评论区发表评论。
- 登录用户可上传评论附图（最多 5 张）。
- 若博主开启了「游客评论」，未登录用户也可填写昵称后评论（游客不能上传图片）。

### 个人中心

- 点击右上角头像进入个人中心。
- **更换头像**：点击头像右下角 ✎ 按钮上传（最大 2MB，支持 jpg/png/gif/webp）。
- **我回复过的主题**：列出你评论过的所有博文，点击即可跳回首页并自动打开该博文。
- **密保设置**：可修改密保问答。

### 忘记账号？

- **忘记用户名**：通过邮箱 + 密保答案找回。
- **忘记密码**：通过用户名 + 邮箱 + 密保答案重置。
- 密保答案答错 2 次将锁定 24 小时，请谨慎作答。

### 后台管理（管理员）

管理员登录后，点击导航栏「后台管理」进入：

- **博客设置**：站点名称、简介、是否开放注册、是否开放评论、是否允许游客评论。
- **AI 配置**：AI 服务地址（OpenAI 兼容）、API Key、模型名称。
- **自动任务**：数据源 RSS 链接、执行计划（cron 表达式）、**AI 洗稿指令**（自定义 System Prompt，留空使用内置兜底指令）。
- **用户管理**：查看用户、修改角色（user/admin）、删除用户（其博文一并删除）。
- **博文管理**：查看全部博文、删除任意博文、**置顶/取消置顶**（可设置截止时间，留空为永久置顶）。
- **标签管理**：查看标签、删除标签。

## ⚙️ 配置项

通过环境变量配置（Docker 中在 `docker-compose.yml` 的 `environment` 中设置）：

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `NIKOBLOG_PORT` | `8080` | 服务端口 |
| `NIKOBLOG_DATA_DIR` | `./data` | 数据目录（数据库 + 上传图片） |
| `NIKOBLOG_JWT_SECRET` | 开发默认值 | JWT 密钥，**生产必须修改** |

## 📁 数据存储

- 数据库：`data/nikoblog.db`（SQLite 单文件）
- 上传图片：`data/uploads/`

备份时只需备份 `data` 目录即可。

## 🛠 技术栈

- 后端：Go + Gin + GORM + SQLite
- 前端：Vue3 + Vite + Tailwind CSS
- 认证：JWT

技术细节见 [ARCHITECTURE.md](ARCHITECTURE.md)。
